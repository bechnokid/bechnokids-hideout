## What is a "clique"?

Web cliques were a fun way to show off the things you're into, what you're like, and also find like-minded people. Some have member lists, some do not. Some permit members to claim one of the same thing, and others don't. Regardless of how they're managed, they're all pretty fun.

Listed below are some mini-cliques that you can just copy and paste without needing to join a member list. My only request is that you save any image from this page onto your own server. Thanks, and have fun!
